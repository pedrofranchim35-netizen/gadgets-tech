Sobre esta Atividade Prática

Este projeto foi construído respeitando rigorosamente os critérios do 4º Bimestre da disciplina de Desenvolvimento Web (Prof. Danilo Bezerra):

  • Sem Frameworks: Desenvolvido exclusivamente com HTML5 semântico, CSS3 puro (Flexbox/CSS Grid responsivo) e JavaScript Vanilla.
  • Renderização Dinâmica: Os dados dos gadgets são carregados a partir de products.js e manipulados via DOM em main.js.
  • Filtros e Busca em Tempo Real: Filtragem por categorias e pesquisa textual instantânea.
  • Persistência de Dados: O carrinho salva automaticamente seus itens e quantidades no localStorage do navegador em cart.js.
